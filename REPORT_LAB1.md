## Цель работы

Настроить виртуальное окружение Python, разработать контроллеры приложения и организовать маршруты для обработки HTTP-запросов.

Практическая часть представлена на примере проекта `lab1-first-http-server`, реализованного на Flask. В методических указаниях рассматривается Django; в данном проекте функции контроллеров и регистрация маршрутов находятся в одном файле `app.py`.

## Ход выполнения лабораторной работы

### Задание 1. Подготовка среды и создание HTTP-сервера

Для разработки приложения используется Python и веб-фреймворк Flask. Основной файл проекта — `app.py`, зависимости перечислены в `requirements.txt`.

Структура проекта:

```text
lab1-first-http-server/
├── app.py
├── requirements.txt
├── README.md
├── curl_commands.txt
└── screenshots/
```

Для подготовки среды необходимо создать виртуальное окружение:

```bash
python -m venv venv
```

Активация окружения в Windows PowerShell:

```powershell
.\venv\Scripts\Activate.ps1
```

Проверка установленных пакетов:

```bash
python -m pip list
```

Виртуальное окружение позволяет установить зависимости проекта отдельно от остальных проектов Python. В архиве также присутствует каталог `venv`; для работы на другом компьютере окружение следует создать заново.

Установка зависимостей и запуск приложения:

```bash
python -m pip install -r requirements.txt
python app.py
```

Объект приложения создаётся выражением `app = Flask(__name__)`. Сервер запускается на порту `3000` с параметром `debug=True`, который включает отладочный режим и автоматическую перезагрузку при изменении кода.

Корневой маршрут реализован следующим образом:

```python
@app.route('/')
def home():
    return 'Добро пожаловать домой'
```

При GET-запросе к `http://127.0.0.1:3000/` ожидается текстовый ответ:

```text
Добро пожаловать домой
```

### Задание 2. Реализация API сотрудников и офисов

В проекте реализованы маршруты для получения списка сотрудников, списка офисов и обработки идентификатора сотрудника.

| Метод | Маршрут | Назначение |
|---|---|---|
| GET | `/` | Приветствие |
| GET | `/api/employees` | Список сотрудников |
| GET | `/api/offices` | Список офисов |
| GET | `/api/employees/<int:employee_id>` | Возврат переданного идентификатора |

Данные сотрудников и офисов задаются в коде списками словарей Python. Функция `jsonify()` преобразует эти структуры в JSON-ответ.

Для запроса списка сотрудников можно использовать команду:

```bash
curl http://127.0.0.1:3000/api/employees
```

Ожидаемое содержимое ответа:

```json
[
  {"id": 1, "name": "Иван Иванов", "position": "Developer"},
  {"id": 2, "name": "Анна Петрова", "position": "Designer"},
  {"id": 3, "name": "Сергей Смирнов", "position": "Manager"}
]
```

**Пример 3 — Список сотрудников в формате JSON**

Список офисов запрашивается командой:

```bash
curl http://127.0.0.1:3000/api/offices
```

Ожидаемое содержимое ответа:

```json
[
  {"id": 1, "city": "Москва", "address": "ул. Центральная, 10"},
  {"id": 2, "city": "Санкт-Петербург", "address": "Невский проспект, 25"},
  {"id": 3, "city": "Ставрополь", "address": "ул. Ленина, 50"}
]
```

**Пример 4 — Список офисов в формате JSON**

Параметризованный маршрут принимает целочисленный идентификатор из URL:

```python
@app.route('/api/employees/<int:employee_id>')
def get_employee(employee_id):
    return jsonify({
        "requestedId": employee_id,
        "status": "success"
    })
```

При запросе `http://127.0.0.1:3000/api/employees/3` ожидается ответ:

```json
{"requestedId": 3, "status": "success"}
```

Данный обработчик демонстрирует передачу параметра в функцию. Поиск сотрудника по идентификатору и проверка его существования в этой версии приложения не выполняются.

### Задание 3. Логирование запросов и обработка ошибок

Перед обработкой каждого запроса Flask вызывает функцию с декоратором `@app.before_request`:

```python
@app.before_request
def log_request():
    print(
        f"[{time.strftime('%Y-%m-%d %H:%M:%S')}] "
        f"{request.method} {request.path}"
    )
```

В терминал выводятся дата, время, HTTP-метод и путь. Формат записи:

```text
[ГГГГ-ММ-ДД ЧЧ:ММ:СС] GET /api/employees
```

Для неизвестного маршрута предусмотрен обработчик:

```python
@app.errorhandler(404)
def not_found(error):
    return jsonify({
        "error": "Not Found"
    }), 404
```

Например, запрос `http://127.0.0.1:3000/anything` должен вернуть код `404` и JSON:

```json
{"error": "Not Found"}
```

В этом проекте роль контроллеров выполняют функции `home()`, `employees()`, `offices()` и `get_employee()`. Декораторы `@app.route()` связывают URL с соответствующими функциями. Данные о текущем запросе доступны через импортированный объект `request`.

Путь запроса в приложении:

```text
Клиент → Flask → логирование → обработчик маршрута → HTTP-ответ
```

При отсутствии подходящего маршрута формируется ответ через обработчик ошибки 404.

### Полный код программы

```python
from flask import Flask, jsonify, request
import time

app = Flask(__name__)

@app.before_request
def log_request():
    print(
        f"[{time.strftime('%Y-%m-%d %H:%M:%S')}] "
        f"{request.method} {request.path}"
    )


@app.route('/')
def home():
    return 'Добро пожаловать домой'


@app.route('/api/employees')
def employees():
    data = [
        {
            "id": 1,
            "name": "Иван Иванов",
            "position": "Developer"
        },
        {
            "id": 2,
            "name": "Анна Петрова",
            "position": "Designer"
        },
        {
            "id": 3,
            "name": "Сергей Смирнов",
            "position": "Manager"
        }
    ]

    return jsonify(data)

@app.route('/api/offices')
def offices():
    data = [
        {
            "id": 1,
            "city": "Москва",
            "address": "ул. Центральная, 10"
        },
        {
            "id": 2,
            "city": "Санкт-Петербург",
            "address": "Невский проспект, 25"
        },
        {
            "id": 3,
            "city": "Ставрополь",
            "address": "ул. Ленина, 50"
        }
    ]

    return jsonify(data)

@app.route('/api/employees/<int:employee_id>')
def get_employee(employee_id):
    return jsonify({
        "requestedId": employee_id,
        "status": "success"
    })


@app.errorhandler(404)
def not_found(error):
    return jsonify({
        "error": "Not Found"
    }), 404


if __name__ == '__main__':
    app.run(port=3000, debug=True)
```

### Особенности реализации

Приложение является учебным сервером с открытыми GET-маршрутами. Аутентификация и проверка прав доступа не реализованы. Учётные записи, пароли, сессии и токены не создаются и не проверяются. Данные хранятся непосредственно в коде; подключение к базе данных отсутствует.

## Соответствие методическим указаниям

Создание виртуального окружения, запуск сервера, реализация функций обработки запросов и настройка маршрутов представлены в проекте средствами Flask.

Методические указания описывают реализацию на Django: создание проекта через `startproject`, приложения через `startapp`, его регистрацию в `INSTALLED_APPS`, контроллеры в `views.py` и подключение маршрутов приложения через `include()`. Эти элементы в текущем Flask-проекте отсутствуют. Для выполнения методики именно на Django потребуется отдельная реализация.
